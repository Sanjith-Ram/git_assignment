GIT COMMANDS USED IN THIS ASSIGNMENT

SETUP
1. mkdir git_assignment
   Creates a new project folder.
2. cd git_assignment
   Moves into the project folder.
3. echo "<h1>Home Page</h1>" > index.html
   Creates index.html with some content (same for about.html).
4. git init
   Initializes an empty Git repository in the folder.
5. git branch -M main
   Renames the current branch to main.
6. ls
   Lists files in the current folder.
7. git status
   Shows the state of the working directory and staging area.
8. git config --global user.name "Your Name"
   Sets the author name used in commits.
9. git config --global user.email "your@email.com"
   Sets the author email used in commits.

COMMITS AND HISTORY
10. git add .
    Stages all changed files for the next commit.
11. git add <filename>
    Stages one specific file.
12. git commit -m "message"
    Saves the staged changes as a commit with a message.
13. git log --oneline
    Shows the commit history in a short, one-line format.
14. git log --oneline --graph --all
    Shows history as a graph, including all branches.

BRANCHING AND MERGING
15. git branch feature
    Creates a new branch named feature.
16. git checkout feature
    Switches to the feature branch.
17. git branch
    Lists all branches; the current one is marked with *.
18. git checkout main
    Switches back to the main branch.
19. git merge --no-ff feature -m "Merge feature branch into main"
    Merges feature into main and always creates a merge commit.

GITIGNORE
20. echo "*.log" > .gitignore
    Creates .gitignore and adds a rule to ignore all .log files.
21. echo "temp/" >> .gitignore
    Appends a rule to ignore the temp folder.
22. cat .gitignore
    Displays the contents of the .gitignore file.
23. mkdir temp
    Creates the temp folder used to test the ignore rule.

UNDO
24. git reset --hard HEAD~1
    Removes the last commit and discards its changes from the files.
25. cat index.html
    Displays the file content to verify the undo.

GITHUB
26. git remote add origin <URL>
    Links the local repository to the GitHub repository.
27. git remote -v
    Shows the remote URLs linked to the repository.
28. git push -u origin main
    Pushes main to GitHub and sets it as the upstream branch.
29. git push origin feature
    Pushes the feature branch to GitHub.
